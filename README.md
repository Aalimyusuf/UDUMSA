# UDUMSA

## Overview

This is a frontend web application built using React, TypeScript, and Vite.
The project focuses on building a clean, responsive, and scalable UI.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS

## Project Structure

* `components/` – Reusable UI components
* `pages/` – Application pages
* `layouts/` – Layout wrappers
* `services/` – API logic
* `types/` – TypeScript types

## Getting Started

npm install
npm run dev

## Features

* Responsive Navbar
* Hero Section
* Clean component architecture
